# 🏠 House Price Prediction using Linear Regression

A simple Machine Learning project that predicts house prices using the **Linear Regression** algorithm. The project includes data preprocessing, model training, evaluation metrics, and prediction.

---

## 📌 Project Overview

This project demonstrates the complete workflow of a supervised machine learning model:

- Load and analyze housing data
- Preprocess the dataset
- Train a Linear Regression model
- Evaluate the model using common metrics
- Predict house prices based on input features

This project was built as part of my Machine Learning learning journey.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/CmdMayank/House-Price-Prediction.git
```

### 2. Navigate into the project

```bash
cd House-Price-Prediction
```

### 3. Create a virtual environment (Optional)

```bash
python3 -m venv .venv
```

### 4. Activate the virtual environment

#### macOS/Linux

```bash
source .venv/bin/activate
```

#### Windows

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the project

```bash
python3 main.py
```
